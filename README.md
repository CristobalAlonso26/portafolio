# Portafolio de Cristobal Ramos

Portafolio personal de **Cristobal Ramos**, desarrollador backend y fullstack y estudiante de
Ingeniería Civil Informática en la Universidad de La Frontera.

Sitio estático de una sola página, con un diseño minimalista y responsive, que reúne perfil
profesional, proyectos, herramientas y vías de contacto.

## Secciones

- **Sobre mí:** formación, enfoque de trabajo, ubicación, disponibilidad e idiomas.
- **Proyectos:** DeskFlow, Security Vulnerability Analysis Pipeline, RL Factory y Comparador de PDFs,
  con descripción, stack tecnológico y enlaces.
- **Skills:** backend, frontend, bases de datos y herramientas.
- **Contacto:** email, GitHub y LinkedIn.

## Características

- Interfaz responsive con menú móvil.
- Navegación por secciones y enlaces directos a cada proyecto.
- Iconografía SVG inline para redes, tecnologías y stacks.
- Sin frameworks ni proceso de build.

## Tecnologías

HTML5, CSS3 y JavaScript. La tipografía usa Space Grotesk e Inter desde Google Fonts, y los iconos
están embebidos como SVG.

## Estructura

```
.
├── index.html
├── styles.css
├── script.js
└── assets/
    └── favicon.svg
```

## Ejecutar localmente

Abre `index.html` en el navegador o levanta un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
